# GW review

这是一个按需的轻量评议工作流，不自动创建并行 Agent、多模型投票或额外付费调用。审查独立性不等于已经由外部专家验证。

## 执行步骤

1. **确定审查对象与基准**
   - 获取原始问题、输入、公式、结果、来源和适用约定，而不只阅读最终结论。
   - 有 GWRC 输出时读取 `run.json` 与 `report.md`，核对输入 SHA-256、参数、软件版本、时间、Git commit（若有）、警告和失败状态。
   - 缺少原始输入或来源时，将对应部分标为无法独立核验，而不是推测补齐。
2. **检查科学定义**
   - 核对 Fourier/PSD 约定、实复数据、矩阵维度、Gaussian 和独立性假设、探测器及通道定义。
   - 区分奇异半正定、严格正定、数值满秩和病态。检查容差是否相对尺度合理，绝对容差是否带有相应量的单位。
   - Fisher 任务检查是否误用了固定协方差公式，或把简化模型扩展成未经验证的 LISA/SGWB 结论。
3. **独立复算关键部分**
   - 优先使用解析参考、另一种推导、独立数值路径或受控极限。只重复同一段代码不构成充分独立验证。
   - 复用 GWRC CLI 时选择新的输出目录，保留原记录；不要覆盖证据。
   - 不因命令退出码为 0 就跳过物理假设、来源或适用范围检查。
4. **审查证据与复现边界**
   - 检查引用是否真实、主张是否有定位、全文是否实际读取、synthetic 数据是否被误称为观测。
   - 区分未运行、运行失败、数值检查未通过、通过但有警告和科学结论未验证。
   - 检查公开材料是否可能含私有数据、令牌、个人路径或受限合作资料；有疑问时停止公开并报告。
5. **形成可执行结论**

按严重程度列出：

- **阻塞**：错误结论、无效数学前提、伪造/不可核对来源、敏感信息或无法复现的关键结果。
- **重要**：缺失约定、未处理病态、证据覆盖不足、过度外推或缺少必要独立检查。
- **建议**：不影响当前正确性但可提高可读性、维护性或复现性的改进。

每项给出具体证据、位置、影响和建议修正。最后列明已实际检查的范围、未检查的范围及仍需研究人员判断的问题。不要以“模型也同意”替代证据。
