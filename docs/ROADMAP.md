# GWRC 路线图

## 当前 MVP：0.1.0

范围是本地、离线可测试的 covariance/PSD/Fisher 工具、JSON/Markdown 记录、四个 Skills 和最小 ARC 文献元数据桥。路线图中其他能力均不是当前功能承诺。

## 当前用户可用性阶段

已验证用户级 Skill 安装、PATH 启动器、安全卸载、wheel 资源，以及 WSL2 Ubuntu 上固定 ARC/AC commit 的官方 runtime、公开论文结构读取和 GWRC runtime 适配。`scripts/validate_arc_linux.sh` 固化该流程。

仍需完成真实 Kimi/Codex 宿主 smoke 和未参与开发的组员验收；在此之前不宣称 v0.2.0 用户验收完成。Windows 原生 ARC 文件锁修复、macOS 验证和上游协作另行处理。不建设 GWRC Server。

## 下一阶段建议（按优先级）

1. **完成可复现的 ARC 文献阅读桥**
   - 在实际支持的 Windows/Linux/Kimi 环境验证固定提交的安装和公开论文读取。
   - 逐步接入结构读取、引用与缓存 provenance；每项都有真实 smoke 和失败降级。先全文证据，再考虑 `arc-domain`，不直接追求自动化大工作流。
2. **加强 PSD 与协方差的来源验证**
   - 在明确 Fourier、采样、窗函数和单双边定义后，增加小型时域到 PSD/协方差估计示例。
   - 使用解析噪声、蒙特卡洛分布和尺度测试检查估计偏差，不先做大规模探测器流水线。
3. **扩展可验证的统计模型**
   - 增加通用 Gaussian log-likelihood、参数相关协方差 Fisher 项和数值导数检查。
   - 复频域、多通道、A/E/T 或 SGWB 模型只有在定义、通道相关结构和独立参考结果明确后分别实现。
4. **强化跨宿主与复现契约**
   - 对 Kimi/Codex/Claude 做真实 Skill 发现和显式调用测试，再决定插件打包。
   - 为 `gwrc.run.v1` 提供版本化 JSON Schema、记录验证命令和环境锁定导出；不急于引入数据库。
5. **建立小组共享的公开科研示例与数据登记规范**
   - 增加经授权的小型公开数据、来源/许可证、校验和与私有数据边界。
   - 根据真实用户需求再评估共享服务器、只读研究资料索引和计算集群适配。

## 暂不开发

独立训练/微调模型、完整 Web 前端、多用户账户、复杂数据库/向量平台、分布式编排、自动 HPC 操作、大规模 LISA/TianQin 流水线、完整 DWD 种群与 SGWB 推断，以及未经验证的多 Agent 自主科研系统。

只有在研究问题、维护者和验证资源明确后才把这些事项重新排期。
